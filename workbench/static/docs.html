SĐiểm mạnh
Apply L4 vượt trội
AI elicitation 7 chiều + generate 6 loại doc — hiếm team nào đạt level này. Hầu hết vẫn đang L2 copy-paste template thủ công.
AI-native by design
Không phải retrofit AI vào system cũ. AI là core từ ngày 1: intent detection, elicitation, generation, governance đều AI-first.
ADLC-native
Tài liệu đi thẳng vào pipeline — không phải tool tách rời cần sync thủ công. Tech Design → Discovery → Spec là một luồng liên tục.
SDD methodology embedded
Vault hiện thực hóa Spec Driven Development: viết spec trước, AI phân tích, generate artifacts. Không code trước document sau.
Governance framework hoàn chỉnh
6 nguồn tri thức, confidence 3 chiều, conflict resolution protocol — đã design. Khi implement = hệ thống tự kiểm chứng.
Role-first design
7 roles với Q&A chuyên biệt, auto-detect intent, quick prompts phù hợp từng góc nhìn nghiệp vụ.
Self-documenting
Vault lưu trữ cả thiết kế của chính nó — roadmap, governance, AI system design đều trong vault.
WĐiểm yếu
Validate ở L2 — rủi ro cao nhất
AI trả lời tự tin nhưng không nói thông tin đến từ đâu, tin cậy mức nào. "Trash in, trash out" sẽ xảy ra khi vault dày lên.
Evolve ở L2 — không tự cải thiện
Không có feedback loop. Vault ngày càng dày nhưng không học từ correction của user. Knowledge stale theo thời gian.
Confidence không được cite trong chat
Nguồn trả lời chỉ hiện filename, không có badge ✅✅/🟡/🔴. User không biết tin bao nhiêu vào câu trả lời.
Role Portal chưa link vào Vault Chat
User đọc Q&A trong Tài liệu nhưng phải tự copy câu hỏi sang chat. Friction cao, adoption thấp.
Document Hub = static templates
Các loại doc với prompts generic, không context-aware từ vault.
Governance implement = 0%
Framework hoàn chỉnh trên paper. Trên thực tế: không có tagging, không có conflict detection, không có staleness watch.
OCơ hội
Legacy doc ingestion
Khi có tài liệu hệ thống cũ → vault biết "tại sao" thay vì chỉ biết "cái gì". Context lịch sử = ít sai lầm repeat.
Single source of truth khi Validate đạt L4
Vault trở thành SOT cho toàn bộ ADLC — từ intent → spec → code → review.
Proactive knowledge delivery
L4+: AI chủ động push tri thức đúng lúc — "Feature bạn đang code liên quan đến ADR-003".
Cross-session AI memory
AI nhớ pattern qua sessions: "Feature này tương tự X đã làm ở project Y".
Feedback loop → model improvement
👍/✏️ corrections → re-rank RAG → AI ngày càng chính xác hơn cho context cụ thể của team.
Role Portal → Vault Chat preset
Link "Mở Chat với role BA" → user landing thẳng vào đúng context, không cần setup thủ công.
Proactive gap detection
Sau khi generate doc: AI scan để tìm gap vs existing artifacts.
TRủi ro / Đe dọa
Trust erosion nếu AI sai mà không nói
Nếu AI trả lời tự tin từ thông tin stale → user bị mislead → mất tin tưởng vào toàn bộ vault.
Vault quality degradation theo thời gian
Không có staleness watch: code thay đổi nhưng artifacts cũ vẫn được RAG search và serve.
Adoption thấp do friction Role → Chat
Nếu role phải "hiểu" hệ thống trước khi dùng → chỉ early adopter dùng.
Legacy docs conflict với code hiện tại
Khi ingest tài liệu cũ mà không cross-check → AI dùng thông tin outdated với confidence cao.
Knowledge silos nếu không có governance
Mỗi project tự quản lý vault riêng, không có cross-project learning.
Overreliance trước khi Validate đủ mạnh
Team tin tưởng AI quá sớm khi Validate vẫn ở L2.
⚡ Ưu tiên hành động từ SWOT
NGAY BÂY GIỜ — Fix W trước T
Implement Validate (P1): source tagging + confidence citation. Chặn trust erosion trước khi vault dày thêm.
TIẾP THEO — Khai thác S để tạo O
Link Role Portal → Vault Chat (P5.1). Dùng Apply strength để giảm adoption friction — quick win không cần infrastructure.
DÀI HẠN — Build O có hệ thống
Legacy ingestion + feedback loop + cross-session memory. Chỉ khi W đã được fix, O mới phát huy tác dụng thực sự.

Benchmark Industry

Những gì các công ty hàng đầu đã làm — và bài học cho hệ thống này

Google
Design Doc culture
Mọi thay đổi significant phải có Design Doc trước khi code. Doc review bởi peers và TL trước khi approve. Không có doc = không có approval.
→ Bài học: Spec trước, code sau — đây chính là SDD. Doc là gate, không phải afterthought.
Stripe
Engineering Wiki + Ownership model
Mỗi doc có owner rõ ràng, có "last reviewed" date, có confidence indicator. AI search nội bộ index toàn bộ wiki + code comments + Slack threads.
→ Bài học: Ownership + currency date = tri thức không stale. Không có owner = tri thức chết.
Netflix
ADR culture + Freedom & Responsibility
Mọi architecture decision được record trong ADR (Architecture Decision Record). Ai cũng có thể đọc lý do tại sao team chọn giải pháp X 3 năm trước.
→ Bài học: Quyết định quan trọng nhất cần được ghi lại với context. Tránh "tại sao code này lại như thế này?"
Spotify
Backstage — Developer Portal
Open-source internal developer portal: catalog tất cả services, docs, ownership, dependencies. Mọi team đều biết cái gì đang chạy ở đâu, do ai maintain.
→ Bài học: Discovery là vấn đề lớn nhất ở scale. Biết "có gì" quan trọng hơn "biết chi tiết".
Microsoft
Viva Topics — AI Knowledge
AI tự động identify topics từ content, tạo topic pages, suggest experts. Khi user đọc doc và gặp term, AI popup context card ngay lập tức.
→ Bài học: Knowledge phải đến với người dùng tại điểm họ cần, không phải bắt họ đi tìm.
Anthropic
Constitutional AI + RLHF
AI học từ feedback của người dùng theo cấu trúc có nguyên tắc rõ ràng (constitution). Không phải học mọi thứ — học có định hướng theo giá trị.
→ Bài học: Feedback loop phải có structure. Không phải mọi feedback đều có giá trị như nhau — confidence hierarchy.

🎤📧💬 Omnichannel AI — Thiết kế mở rộng

Voice · Email · Teams tích hợp vào Vault AI Chat · Đánh giá khả thi và kiến trúc kỹ thuật

🎤 Voice Input — Chi tiết kỹ thuật
Option A: Web Speech API
Browser-native, Chrome/Edge. Không cần backend. Miễn phí. Chỉ cần JS: SpeechRecognition
Option B: Whisper API
Chính xác hơn, đa ngôn ngữ. Ghi âm → base64 → POST /vault/voice/transcribe → Whisper → text. Chi phí: ~$0.006/phút.
→ Triển khai: Thêm 🎤 button vào vault_ui.html, 1 endpoint mới. Không ảnh hưởng code cũ.
📧 Email Integration — Chi tiết kỹ thuật
Microsoft Graph API (Outlook)
OAuth2 PKCE → access token → GET /me/messages → parse → index vào vault.db. Người dùng hỏi AI: "Tóm tắt email hôm nay từ khách hàng"
Gmail API
Google OAuth2 → gmail.readonly scope → messages.list → messages.get → tương tự.
→ Email body trở thành context RAG. Vault trả lời: "Email từ John hôm nay yêu cầu gì?"
💬 Teams Bot — Chi tiết kỹ thuật
Phase 1: Incoming Webhook (đơn giản nhất)
ADLC pipeline xong → POST đến Teams webhook URL → thông báo kết quả. Không cần Azure.
Phase 2: Azure Bot Framework
Đăng ký bot trên Azure → deploy endpoint /vault/teams/bot → bot tham gia channel → @VaultAI → trả lời từ knowledge base.
→ "@VaultAI tóm tắt backlog sprint này" → bot query vault → reply ngay trong Teams.
⚠️ Lưu ý quan trọng trước khi triển khai
🔐 Privacy
Email và Teams chứa thông tin nhạy cảm. Cần: data retention policy, encrypt at rest, user consent flow trước khi sync.
📋 Permissions
MS Graph cần admin consent cho org-wide. Gmail cần Google Cloud project + OAuth verification nếu > 100 users.
💰 Chi phí
Whisper: ~$0.006/phút. MS Graph: free (E3/E5 license). Azure Bot: free tier đủ dùng (~10k msg/tháng).
